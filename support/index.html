무엇을 도와드릴까요?

진짜 가계부 1.0은 로그인 없이 기기에만 데이터를 저장합니다. 서버에서 장부나 백업 암호를 복구할 수 없습니다.

데이터 백업

설정 → 데이터 → 암호화 백업에서 파일을 만들고 암호와 파일을 서로 다른 안전한 곳에 보관하세요.

기기 변경

이전 기기에서 암호화 백업을 만든 뒤 새 기기에서 가져오세요. 앱 삭제 전에 복원을 확인하는 것을 권장합니다.

카드 자동 결제

실제 은행 결제가 아닙니다. 결제일에 연결 계좌에서 카드 부채로 이동하는 앱 내부 원장 기록입니다.

CSV 내보내기

CSV는 암호화되지 않은 평문입니다. 메신저나 공개 저장소보다 사용자가 통제하는 안전한 위치를 이용하세요.

문제 신고

기기 종류, iOS 버전, 앱 버전, 재현 순서를 적어주시면 확인에 도움이 됩니다. 실제 거래명·금액·영수증·백업 파일·암호는 제거해주세요.
