개인정보처리방침

시행일: 2026년 7월 18일

진짜 가계부는 로그인·광고·분석 SDK 없이 동작하며, 사용자가 입력한 금융 기록을 앱 서버로 수집하거나 전송하지 않습니다.

1. 처리하는 정보

거래, 자산, 분류, 예산, 반복 일정과 사용자가 선택한 영수증 이미지는 이 기기의 앱 전용 저장공간에서만 처리됩니다. 기기 인증을 사용할 때 생체정보나 기기 암호는 운영체제가 확인하며 앱은 이를 읽거나 저장하지 않습니다.

2. 외부 전송과 제3자 제공

1.0 버전은 클라우드 동기화, 광고, 원격 분석과 원격 오류 수집 기능을 포함하지 않습니다. 사용자가 시스템 공유 화면에서 백업이나 CSV를 직접 공유하는 경우 선택한 외부 앱의 정책이 적용됩니다.

3. 보관과 삭제

데이터는 사용자가 앱에서 전체 초기화를 실행하거나 앱을 삭제할 때까지 기기에 남습니다. 서버 복구본은 없습니다. 거래의 영수증을 삭제하면 앱은 저장된 이미지 본문을 비우며, 운영체제 저장매체의 포렌식 수준 즉시 삭제까지 보장하지는 않습니다.

4. 백업과 보안

전체 백업은 사용자가 지정한 암호로 Argon2id 키 파생과 AES-256-GCM 인증 암호화를 적용합니다. 암호를 잊으면 복구할 수 없습니다. CSV는 호환성을 위한 평문 파일이므로 안전한 위치와 공유 대상을 사용해야 합니다. 앱 데이터는 운영체제 샌드박스와 iOS Data Protection의 보호를 받지만 SQLite 자체 암호화로 표현하지 않습니다.

5. 사용자의 선택

사용자는 언제든지 개별 기록을 수정·삭제하고, 전체 초기화로 로컬 데이터를 삭제할 수 있습니다. 기기 잠금은 기본 OFF이며 설정에서 켜거나 끌 수 있습니다.

6. 문의

일반 지원은 지원 페이지와 GitHub Issues를 이용할 수 있습니다. 실제 금융정보, 영수증, 백업 파일이나 백업 암호를 공개 이슈에 첨부하지 마세요. 보안 문제는 저장소의 비공개 취약점 신고 기능을 이용해주세요.

7. 변경 안내

수집·전송 범위가 달라지는 기능을 추가할 때 이 방침을 먼저 갱신하고 앱과 이 페이지에서 시행일을 알립니다.
